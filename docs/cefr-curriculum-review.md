# CEFR Curriculum Review - Draft Before DBEC Update

This draft reorganizes the lesson plan around CEFR-style communicative outcomes.
It does not change the DBEC site yet.

## What Changed

- Added a clear `Can do` outcome to each unit.
- Treated difficult A1 grammar as fixed classroom/useful chunks instead of full grammar systems.
- Moved several A1-heavy items into A2 or A2+.
- Corrected the B1 section flow and removed the duplicated `Section 10` issue.
- Made B2 more task-based, with grammar serving debate, analysis, professional communication, and persuasion.
- Added review/project checkpoints so the course cycles back through skills instead of moving only grammar-forward.
- Kept pronunciation, but tied it to intelligibility and speaking outcomes.

## A1 Beginner

Target: students can handle immediate personal, classroom, home, routine, shopping, and town situations with short, prepared language.

### A1 Project

Can introduce themselves, describe family/home/routine, order something simple, and ask for a place in town.

Moved out of A1 as full grammar systems:

- `Could you...?` -> A2 polite requests.
- `How much/How many` as grammar -> A2 quantities.
- `object pronouns` -> A2 shopping/services.
- `was/were` and last weekend -> A2 past events.
- tag questions -> later, or only as fixed conversational chunks.
