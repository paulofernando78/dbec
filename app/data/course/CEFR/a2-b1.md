## CEFR

- A2 ➜ B1

# Unit 1 - Looking Back
**Lesson 1 - Asking About the Past** - By the end of this lesson, students will be able to use past-tense questions with did and was/were to ask people about their past.
**Lesson 2 - When I Was Younger** - By the end of this lesson, students will be able to discuss their childhoods using used to.

# Unit 2 - City Life
**Lesson 1 - City Challenges** - By the end of this lesson, students will be able to discuss city issues and public services using expressions of quantity and compound nouns.
**Lesson 2 - Could You Tell Me?** - By the end of this lesson, students will be able to ask indirect questions.

# Unit 3 - Homes and Changes
**Lesson 1 - Finding the Right Home** - By the end of this lesson, students will be able to evaluate and compare houses and apartments using too and comparatives.
**Lesson 2 - I Wish Things Were Different** - By the end of this lesson, students will be able to discuss changes in their lives using I wish.

# Unit 4 - Experiences and Food
**Lesson 1 - Life Experiences** - By the end of this lesson, students will be able to describe personal experiences using the past tense and the present perfect.
**Lesson 2 - Recipe Steps** - By the end of this lesson, students will be able to describe recipes using sequence adverbs.

# Unit 5 - Plans and Travel
**Lesson 1 - Future Plans** - By the end of this lesson, students will be able to describe plans using the future with be going to and will.
**Lesson 2 - Smart Travel** - By the end of this lesson, students will be able to give travel advice.

# Unit 6 - Everyday Requests
**Lesson 1 - Could You Turn It Down?** - By the end of this lesson, students will be able to use two-part verbs to make and respond to requests.
**Lesson 2 - Would You Mind?** - By the end of this lesson, students will be able to make and respond to requests using modals and Would you mind?

# Unit 7 - Uses and Suggestions
**Lesson 1 - What Is It For?** - By the end of this lesson, students will be able to use infinitives and gerunds to describe uses and purposes.
**Lesson 2 - Here's an Idea** - By the end of this lesson, students will be able to use imperatives and infinitives to give suggestions.

# Unit 8 - Celebrations and Customs
**Lesson 1 - Special Days** - By the end of this lesson, students will be able to describe celebrations and annual events using relative clauses of time.
**Lesson 2 - Customs and Traditions** - By the end of this lesson, students will be able to describe customs using adverbial clauses of time.

# Unit 9 - Time and Consequences
**Lesson 1 - Then, Now, and Next** - By the end of this lesson, students will be able to use the past, present, and future tenses.
**Lesson 2 - What If?** - By the end of this lesson, students will be able to discuss consequences using conditional sentences with if clauses.

# Unit 10 - Working Life
**Lesson 1 - Skills at Work** - By the end of this lesson, students will be able to discuss job skills using gerunds and short responses.
**Lesson 2 - The Right Job** - By the end of this lesson, students will be able to discuss the kinds of jobs they want and don't want using clauses with because.

# Unit 11 - Our World
**Lesson 1 - Built by Genius** - By the end of this lesson, students will be able to discuss famous landmarks, monuments, and works of art using the passive with by (simple past).
**Lesson 2 - Countries in Focus** - By the end of this lesson, students will be able to discuss key features of countries around the world using the passive without by (simple present).

# Unit 12 - Events and Activities
**Lesson 1 - When It Happened** - By the end of this lesson, students will be able to discuss events, accidents, and accomplishments in their lives using the past continuous and the simple past.
**Lesson 2 - What Have You Been Doing?** - By the end of this lesson, students will be able to discuss events using the present perfect continuous.

# Unit 13 - Entertainment
**Lesson 1 - Worth Watching** - By the end of this lesson, students will be able to discuss books, movies, and TV programs using participles as adjectives.
**Lesson 2 - Hollywood Stories** - By the end of this lesson, students will be able to discuss more about movies and famous Hollywood names using relative clauses.

# Unit 14 - Communication and Rules
**Lesson 1 - What Does That Gesture Mean?** - By the end of this lesson, students will be able to explain gestures using modals and adverbs.
**Lesson 2 - Signs and Rules** - By the end of this lesson, students will be able to discuss signs using terms of permission, obligation, and prohibition.

# Unit 15 - Imaginary Worlds
**Lesson 1 - What Would You Do?** - By the end of this lesson, students will be able to discuss imaginary situations using unreal conditional sentences with if clauses.
**Lesson 2 - If Only I Had Known** - By the end of this lesson, students will be able to discuss predicaments using the past modals would have and should have.

# Unit 16 - Reporting What People Say
**Lesson 1 - Excuses and Requests** - By the end of this lesson, students will be able to discuss excuses and requests using reported speech.
**Lesson 2 - What Did They Say?** - By the end of this lesson, students will be able to use reported speech to discuss statements that other people made.
