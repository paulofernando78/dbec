## CEFR

- Can understand sentences and frequently used expressions related to areas of most immediate relevance (e.g. very basic personal and family information, shopping, local geography, employment).
- Can communicate in simple and routine tasks requiring a simple and direct exchange of information on familiar and routine matters.
- Can describe in simple terms aspects of his/her background, immediate environment and matters in areas of immediate Basic need.

# Unit 1 - New Connections
**Lesson 1 - Meet and Connect** - By the end of this lesson, students will be able to introduce themselves and others using be and possessive adjectives, and ask and answer Wh-questions to find out information about others and to state information about themselves.
**Lesson 2 - Getting to Know You** - By the end of this lesson, students will be able to ask and answer yes/no questions to find out information about others and to state information about themselves.

# Unit 2 - Work and Routine
**Lesson 1 - What Do You Do?** - By the end of this lesson, students will be able to ask and answer questions about occupations using the simple present.
**Lesson 2 - Busy Days** - By the end of this lesson, students will be able to describe routines and daily schedules using time expressions.

# Unit 3 - Shopping Choices
**Lesson 1 - How Much Is That?** - By the end of this lesson, students will be able to use demonstratives, one, and ones to ask about and describe prices.
**Lesson 2 - Better Choices** - By the end of this lesson, students will be able to discuss preferences using comparisons with adjectives.

# Unit 4 - Entertainment
**Lesson 1 - What Do You Watch?** - By the end of this lesson, students will be able to discuss entertainment likes and dislikes using yes/no and Wh-questions with do.
**Lesson 2 - Join Us!** - By the end of this lesson, students will be able to make, accept, and decline invitations using would and verb + to + verb.

# Unit 5 - Family Life
**Lesson 1 - Family Snapshots** - By the end of this lesson, students will be able to describe families and ask and answer questions using the present continuous.
**Lesson 2 - Big Family, Small Family** - By the end of this lesson, students will be able to use quantifiers to describe families.

# Unit 6 - Active Free Time
**Lesson 1 - Active Life** - By the end of this lesson, students will be able to discuss sports and exercise habits.
**Lesson 2 - How Often?** - By the end of this lesson, students will be able to ask and answer questions about frequency of free-time activities.

# Unit 7 - Past Activities
**Lesson 1 - What Did You Do?** - By the end of this lesson, students will be able to discuss daily and free-time activities using the simple past with regular and irregular verbs.
**Lesson 2 - Vacation Memories** - By the end of this lesson, students will be able to discuss vacations using the past tense of be.

# Unit 8 - Places to Live
**Lesson 1 - Around Here** - By the end of this lesson, students will be able to ask about and describe places using there is/there are and prepositions of place.
**Lesson 2 - My Neighborhood** - By the end of this lesson, students will be able to describe features of a neighborhood using quantifiers.

# Unit 9 - People Around Us
**Lesson 1 - What Do They Look Like?** - By the end of this lesson, students will be able to describe people's physical appearance.
**Lesson 2 - Which Person?** - By the end of this lesson, students will be able to identify people using modifiers with participles and prepositions to describe how they look, what they are wearing, what they're doing, and where they are.

# Unit 10 - Life Experience
**Lesson 1 - Done Yet?** - By the end of this lesson, students will be able to describe recent activities using the present perfect, already, and yet.
**Lesson 2 - Life Experiences** - By the end of this lesson, students will be able to describe experiences from the recent and distant past using the present perfect, simple past, for, and since.

# Unit 11 - Local Guide
**Lesson 1 - Hometown Guide** - By the end of this lesson, students will be able to describe their hometowns using adjectives, adverbs, and conjunctions, and make suggestions about places using can and should.
**Lesson 2 - You Should Go!** - By the end of this lesson, students will be able to make suggestions about places using can and should.

# Unit 12 - Health Care
**Lesson 1 - Health Solutions** - By the end of this lesson, students will be able to state health problems and give advice using adjective + infinitive and noun + infinitive.
**Lesson 2 - At the Pharmacy** - By the end of this lesson, students will be able to ask for advice and give suggestions about health care products using can, could, and may.

# Unit 13 - Food and Dining
**Lesson 1 - Same Taste** - By the end of this lesson, students will be able to agree and disagree about food preferences using so, too, neither, and either.
**Lesson 2 - Ready to Order** - By the end of this lesson, students will be able to use would and will to order food at a restaurant.

# Unit 14 - Our World
**Lesson 1 - Amazing Geography** - By the end of this lesson, students will be able to describe geography using comparative and superlative forms of adjectives.
**Lesson 2 - How Far?** - By the end of this lesson, students will be able to describe distances and measurements, and ask and answer questions with how.

# Unit 15 - Plans and Messages
**Lesson 1 - Future Calendar** - By the end of this lesson, students will be able to discuss future activities and plans using the present continuous, be going to, and time expressions.
**Lesson 2 - Pass It On** - By the end of this lesson, students will be able to give messages using tell and ask.

# Unit 16 - Moving Forward
**Lesson 1 - Life Changes** - By the end of this lesson, students will be able to describe changes in their lives using the comparative and present, past, and present perfect tenses.
**Lesson 2 - The Next Chapter** - By the end of this lesson, students will be able to describe plans for the future using verb + infinitive.
